# Plan: 家族の設定への導線を分かりやすくする

Issue: [#186](https://github.com/kchan-lab/hoopo/issues/186)
設計の正: docs/REQUIREMENTS.md §4.2-1(ホーム)・§4.2-9(家族の設定)/ docs/DESIGN_GUIDELINES.md(保護者アプリ)
/ CLAUDE.md 絶対原則 2・6

## 目的

ホームから家族の設定へ行く導線が見つけにくい。承認者の指摘(2026-09-19)。
ヘッダー右上の丸ボタンは飾りで押せず、ホームのカードは周りのカードと同じ見た目で
押せることが伝わらない。

## 方針

```
[ヘッダー]  SKC  SKC粉浜・北粉浜…            (太)   ← 押すとメニューが開く
                                            ┌──────────────┐
                                            │ 家族の設定        │
                                            │ 招待コード・連携   │
                                            ├──────────────┤
                                            │ プライバシーポリシー │
                                            ├──────────────┤
                                            │ ログアウト        │
                                            └──────────────┘

[ホーム]    ┌────────────────────────────┐
            │ 家族の設定                → │   ← 矢印を付け、見出しを本文色にして
            │ 招待コードの共有・連携済みの家族 │      周りのカードと区別する
            └────────────────────────────┘
```

### 設計判断

0. **丸ボタンは家族の設定へ直行せず、メニューを開く**(承認者の決定 2026-09-19。当初は直行だった)。
   並べるのは「家族の設定」「プライバシーポリシー」「ログアウト」。
   右上の丸=自分まわりのことをまとめて選べる場所、という慣習に合わせる。
   - **保護者アプリにログアウトは無かったので新設する**(管理画面の `POST /auth/logout` と同じ作り。
     セッション Cookie を消すだけ)。LIFF から開き直すと自動ログインで入り直すため、
     効くのは外部ブラウザで開いたときと、端末を人に渡すとき。**その旨を画面に添える**
   - 確認を挟む(押し間違いで抜けると、保護者は入り直し方が分からない)
1. **ヘッダーの丸ボタンを押せるようにする**。`aria-hidden` の `span` をやめ、
   `aria-label="家族の設定"` を持つリンクにする。他のアプリと同じく、右上の丸=自分まわりの設定、
   という慣習に合わせる。頭文字の表示はそのまま(お子さんが複数いても先頭の1人)。
2. **押せることを縁で示す**。塗りを変えると team-head のロゴ(黒丸)と competing するので、
   既存トークンの枠線を足すだけにする。新しい色は作らない(DESIGN_GUIDELINES)。
3. **ホームのカードは `.choice` 全体ではなく修飾クラスで変える**。`.card.choice` は
   「お子さんを新しく登録する」「ホームへ戻る」でも使っており、そちらは中央寄せの
   選択肢として今の見た目が正しい。家族の設定だけを「次の画面へ進む行」として見せる。
4. **矢印(→)と見出しの文字色で区別する**。塗りつぶしのボタンにすると、ホームの主役
   (次回の練習)より目立ってしまう。絶対原則6(保護者UIは薄いオレンジ・iOS調)の範囲で、
   主役を食わない強さにとどめる。
5. **ヘッダーとカードの両方を残す**(どちらか一方にしない)。ヘッダーは慣習から探す人、
   カードは画面を上から読む人のための導線で、利用者が違う。

6. **メニューは全画面のヘッダーに出す**(承認者の決定 2026-09-19。当初はホームだけ)。
   どの画面からでも同じ場所にあるのが、右上の丸の慣習の値打ち。ホームに戻ってから押す、を強いない。
   - 対象は保護者がログインして見る画面すべて(日程・提出・月謝・チーム・お知らせ・練習の詳細・出場メンバー・家族の設定)
   - **`/privacy` は対象外**(未ログインでも開く画面で、セッションが無いことがある)
   - **`/register` は対象外**(まだお子さんが1人もおらず、頭文字が作れない。設計判断1の「お子さんが無いときは出さない」と同じ理由)
   - 頭文字を出すためにお子さんの情報が要る。**各画面で取り直すのではなく、取得を1か所にまとめる**
     (同じ問い合わせを画面ごとに増やさない)
   - ヘッダーには既に別のものが置かれている画面がある(日程の表示切替、チームの人数)。
     それらと競合しないように収める

7. **左上のチームのマーク(SKC の丸)も全画面のヘッダーに出す**(承認者の決定 2026-09-19)。
   結果、全画面のヘッダーが「SKCマーク / 画面名 / アカウントの丸」で揃う。
   - **マークだけを置き、チーム名は添えない**。モバイル幅(iPhone 15 = 393px)で画面名と
     並べると、名前まで入れると窮屈になる。チーム名が並ぶのはホーム(`.team-head`)だけ
   - **マークはホーム(`/`)へのリンク**。左上のロゴを押すと最初の画面、という慣習に合わせる
   - **見出しの中の戻る矢印(`‹`)はそのまま残す**。あれは「1つ前」でマークと役割が違う。
     消すと1つ前に戻れなくなる
   - **ホーム(`.team-head`)は今のまま**(マークとチーム名とアカウントの丸が既に並んでいる)
   - 見た目は `.team-head .logo` を単独の `.logo` に切り出して共有し、ヘッダー用は
     `.logo.sm` で一段小さくする(34px → 28px)。`.team-head` 配下だけの規則のまま
     コピーしない
   - 対象外は設計判断6と同じ(`/privacy` と `/register`)

## 影響する箇所

- apps/portal: `app/page.tsx`(ヘッダーの丸ボタン・家族の設定のカード)、`app/account-menu.tsx`、
  各画面のヘッダー(日程・提出・月謝・チーム・お知らせ・練習の詳細・出場メンバー・家族の設定)、`app/globals.css`
- docs: REQUIREMENTS §4.2-1・§4.2 のヘッダーの記述
- e2e: ヘッダーの丸ボタンから家族の設定へ行けること・左上のマークからホームへ戻れること
- apps/admin / packages: 変更なし

## 完了条件

- ホームのヘッダー右上のボタンから家族の設定へ行ける(E2E)
- **同じボタンが、保護者がログインして見る全画面のヘッダーに出ている**(E2E で代表的な画面を確認)
- **左上のチームのマークも全画面のヘッダーに出ていて、押すとホームへ戻る**(E2E)
- モバイル幅(393px)で見出しが折り返したり切れたりしない(E2E で見出しの折り返しを見る)
- `/privacy` と `/register` にはマークもアカウントの丸も出ていない
- そのボタンに読み上げ用の名前が付いている(`aria-hidden` ではない)
- ホームの「家族の設定」が、周りのカードと見分けがついて押せると分かる
- 他の `.card.choice`(お子さんを新しく登録する・ホームへ戻る)の見た目は変わっていない
- 新しい色トークンを増やしていない
- mobile 幅のスクリーンショットを承認者に見せて合意している
