# DESIGN_GUIDELINES.md — UIデザイン規範(v6準拠・確定版)

視覚的な基準は `wireframes-v6.html`(全32画面: 保護者15+管理PC8+管理モバイル9)。目標はiOSネイティブアプリの精度。
クリーム背景+テラコッタ強調のような「生成AIっぽい」定番ルックを避け、
背景はニュートラル寄り、オレンジは面で塗らずアクセントとして点で使う。

## 0. 共通の考え方

- ブランド表記(二層): ワードマークは小文字 `hoopo`(--accent単色)、ロックアップは「hoopo − ミニバスれんらくポータル」。ただし保護者画面の主役はチームであり、hoopoは起動画面と「powered by hoopo」に配置する

- 装飾より余白と階層。1画面で強調するのは1要素まで
- アニメーションは最小限(画面遷移のみ)。`prefers-reduced-motion` を尊重
- 3D表示は**後追いリリース**。初期実装は2Dのみ(タブだけ先置きしない。3D追加時にタブを出す)
- 文言: 平易な日本語、動詞で始めるボタン(「提出する」「発行して送信」)。用語統一は CLAUDE.md 参照

## 1. 保護者アプリ(portal)

### 1.1 カラートークン
| token | 値 | 用途 |
|---|---|---|
| --bg | #F5F3EF | 画面背景(ごく薄い温白) |
| --paper | #FFFFFF | カード |
| --ink | #1A1511 | 主要テキスト / 中央タブの黒丸 / CTA |
| --sub | #7D7368 | 補助テキスト |
| --faint | #B3A99E | 非活性・ヒント |
| --hair | rgba(58,42,22,.12) | 罫線 |
| --accent | #EF8432 | 薄いオレンジ(選択・強調・スタンプ) |
| --tint | #FCEBDA | オレンジの淡背景(バッジ・通知) |
| --deep | #9C4E0E | tint上のテキスト |
| --line-green | #06C755 | LINEブランドボタン専用(白文字・両テーマ固定) |

### 1.2 タイポグラフィ
- フォント: `-apple-system, "SF Pro Text", "Hiragino Sans", "Noto Sans JP", sans-serif`
- ラージタイトル 20–22/700、カード見出し 14–15/600、本文 13、補助 11–12、数字は `tabular-nums`
- 太さは 400/600/700 の3段のみ

### 1.3 コンポーネント規約
- **チームヘッダー**: SKC丸ロゴ34px(--ink地・白文字)+「SKC粉浜・北粉浜ミニバスケットボール」2行(13px/800)をホーム上部に常時表示。
  画面最下部に powered by hoopo(9.5px、faint+accentの組み)
- **タブバー(5ボタン)**: ホーム/月謝/日程(中央)/チーム/提出。中央「日程」は50pxの黒丸(--ink)+白アイコンを
  14px浮かせ、アクティブ時のみ丸が --accent。他タブはアイコン22px+ラベル9.5px
- **カード**: radius 16、border 1px rgba(58,42,22,.06)、影なし
- **LINE連絡ボタン**: --line-green 塗り・白文字・radius 14。ホームの未提出アラート直下に全幅配置。
  遷移先はコーチ個別LINEのトークURL
- **ビュートグル**(リスト⇄カレンダー): タイトル右のセグメント。切替は即時、選択状態・入力値は保存して同期
- **カレンダー(2種・日曜始まり)**:
  - 日程ビュー: 練習日= tint地+deep文字(タップ可)、選択中= accent地+白、練習なし= faint(非活性)、他月=さらに淡く
  - 提出ビュー(4状態): 参加= accent塗り+白 / 途中参加・早退= tint地+accent 1.5px枠 / 不参加= #E7E1D8地+打消線 /
    未回答= accent枠のみ。タップで 参加→途中→不参加→未回答 を循環。凡例を下部に必ず置く
- **提出行(リスト)**: 左=日付・時間/場所、右=プルダウン(未回答/参加(全時間)/途中参加・早退/不参加)。
  「途中参加・早退」選択時のみ下段にコメントinputを表示(placeholder例: 11:00ごろ早退します)。
  一括チップ=「すべて『参加』にする/未回答に戻す」。CTAに「回答 n / m 件」を表示
- **月謝スタンプ**: 済= deep色2px円枠+「済」、当月未= accent枠カード+破線円「未」、未来=淡色「–」
- **練習詳細**: ボトムシートではなく**フル画面の詳細ページ**(左上シェブロンで戻る)。
  日付バッジ+時間を大きく、場所/備考は行アイコン付き。練習メニューは「時間 | 内容」の行リスト。
  下部に「出場メンバーはこちら」(アウトラインCTA)と「参加予定を変更する」(inkCTA)
- **コート(出場メンバー・2D)**: **リングを下**にした向き(基準SVG viewBox 300×316 を180度回転)。
  床 #F8ECDD、ライン #DCA878。選手チップ=42px円(写真 or 頭文字、accent 2px枠)+右上ポジションバッジ
  (ink地・白8px)+下に名前9.5px。配置(left/top %): PG 26/27・SG 74/27・SF 12/52・PF 88/52・C 64/70。
  SF/PFの左右とCの寄せ側は編成時に入替可。ベンチは34px円で下段カードに横並び
- **コート(3D・後追い)**: SVG疑似パースで実装(台形フロア+奥にゴールポール/バックボード)。
  選手ピン=接地の影楕円+支柱+顔円(写真)。ライブラリ追加はしない
- **名簿行(チーム)**: 頭文字丸33px(tint/deep)+氏名13px/600+呼び名ひらがな11px(sub)+右端に学年ピル

## 2. 管理アプリ(admin)

### 2.1 カラートークン(モノトーン、ライト/ダーク)
| token | light | dark |
|---|---|---|
| --abg | #F2F2F1 | #151514 |
| --acard | #FFFFFF | #1F1F1E |
| --aink | #1C1C1B | #F0EFEC |
| --asub | #6F6E6A | #A2A19B |
| --ahair | #E3E2DE | #33322F |
| --afield | #F6F6F5 | #262625 |
| --aacc(主ボタン) | #1C1C1B | #F0EFEC |

- オレンジ禁止。状態はモノトーン+テキスト(○/△/×/−、済/−)で表現
- 実装: ルート要素の `data-theme="light|dark"` でCSS変数切替。切替ボタン(月/太陽)をヘッダー常設。
  初期値はOS設定、選択は保存

### 2.2 文字サイズ3段階
- ルートの `data-fs="s|m|l"` → `--afs: 12px / 13.5px / 16px`
- コンテナ `font-size: var(--afs)`、内部はすべて **em** 指定で全体が追随。タップ領域は44px以上を維持

### 2.3 レイアウト・画面別規約
- PC: 左サイドバー170px(ダッシュボード/出欠/欠席者/認定/日程/月謝/部員)。
  モバイル(<640px): **ハンバーガーメニュー**でドロワー表示(左からスライドイン+背面ディム、項目はPC版サイドバーと同一)。テーブルは横スクロール許可
- 塗り(fill)ボタンは「発行してLINEへ送信」「ログイン」などの主要アクションのみ。他はアウトライン
- 出欠マトリクス: ○/△/×/− の4値。△セルのタップで保護者コメントをポップ表示
- 欠席者管理: 日付ピル切替。不参加/途中参加・早退/未回答の3グループでコメント併記
- 認定管理(自動認定+事後確認): 各行にステータスピル「認定済(自動)」+**アウトラインの「無効化」ボタンのみ**。
  承認/却下ボタンは置かない
- LINE通数メーター(n/200)は日程管理とダッシュボードに常設。バーは aink 単色

## 3. アクセシビリティ

- コントラスト: 本文4.5:1以上(両テーマで検証)。tint上は必ず deep を使う
- フォーカスリング可視、タップ領域44px、アイコンボタンには aria-label
- 色だけに依存しない(済/未・出欠4値は文字併記、カレンダーは凡例併設)
